## About

This repository contains my **Day 1 to Day 7 Python practice assignments** from the C-DAC PGCP-BDA Python module.

The assignments are organized day-wise and focus on building Python fundamentals through hands-on programming exercises. The complexity gradually increases from basic syntax and problem-solving to working with files, structured data, object persistence, and databases.

The repository is primarily maintained as:

* A record of my Python learning journey
* A practice and revision resource
* A collection of hands-on programming exercises
* A reference for concepts covered during the Python module

Focused on manipulating and processing strings using indexing, slicing, built-in methods, and formatting.

### Day 3 → Lists & Collections

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/AagmanTiwari/CDAC-Python-Module.git
cd CDAC-Python-Module
```

### 2. Navigate to the Python Module

```bash
cd "Python Module"
```

### 3. Navigate to an Assignment

For example:

```bash
cd "day_07_practice_assignments: File Handling, Data Formats, Serialization & Relational Databases"
```

### 4. Run a Python File

```bash
python3 filename.py
```

For example:

```bash
python3 "Easy Assignments/ex01_structured_csv&json_data_processor.py"
```

> Some assignments may create output files or local database/serialization files while running.
